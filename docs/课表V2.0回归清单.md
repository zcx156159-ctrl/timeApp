# 课表 V2.0 回归清单

| 项目 | 内容 |
|------|------|
| 版本 | V2.0（账号 + 云端 + 多课表 + 同步 + 共享 + PWA） |
| 日期 | 2026-08-12 |
| 用法 | 逐项执行，填 PASS/FAIL；FAIL 备注现象 |

前置：后端 `gradlew.bat -p server fatJar` + `start-web.bat`；客户端最新构建（wasm + desktop）。

## 1. 账号

- [ ] 手机号注册成功（密码 ≥6 位）
- [ ] 邮箱注册成功
- [ ] 注册重复账号提示 400/失败
- [ ] 登录成功（手机号/邮箱均可）
- [ ] 密码错误提示“账号或密码错误”
- [ ] 退出登录 → 再次登录数据恢复

## 2. 多课表

- [ ] 新建课表并自动切换（课程为空）
- [ ] 两个课表各自添加课程，互不串数据
- [ ] 切换课表后网格显示对应课表内容
- [ ] 改名后重启保持
- [ ] 删除当前课表后自动切到第一个

## 3. 云同步

- [ ] 添加/修改课程自动上传（状态“已同步”）
- [ ] 删除课程，另一设备刷新后消失（tombstone）
- [ ] A 改课程时间，B 同步后生效
- [ ] 断网编辑 → 联网后自动推送（离线队列）
- [ ] 启动自动同步

## 4. 共享

- [ ] 生成只读码 → 未登录端“输入共享码查看”载入成功
- [ ] 只读码无法写入（后端 403）
- [ ] 生成可编辑码 → 未登录端可用后端接口写入（客户端写入口暂缺，可选验证）
- [ ] 撤销后，未登录端再载入失败
- [ ] 共享码列表显示权限正确

## 5. 旧版共享码兼容

- [ ] 创建旧 6 位共享码（未登录路径）仍可用
- [ ] 用共享码加入仍可用

## 6. Web PWA

- [ ] 浏览器可“安装应用”（出现安装提示）
- [ ] 断网打开仍能加载页面壳与最近数据（Service Worker 缓存 + localStorage）
- [ ] 联网后恢复同步

## 7. V1.1 回归（快速）

- [ ] 单双周/起止周显隐、周切换
- [ ] 主题切换（右上角）与持久化

- [ ] 上课提醒（桌面/安卓）
- [ ] iCal 导出可导入系统日历
- [ ] 深色模式可读

## 8. 数据持久化

- [ ] 桌面/安卓重启后课程保留
- [ ] Web 刷新后课程保留（localStorage 已启用）
