## 4. 构建与运行命令

```powershell
# 客户端 Web/桌面/安卓
.\gradlew.bat :composeApp:wasmJsBrowserDistribution
.\gradlew.bat :composeApp:desktopJar
.\gradlew.bat :composeApp:assembleDebug
# 单测
.\gradlew.bat :composeApp:desktopTest

# 后端
.\gradlew.bat -p server fatJar
# 冒烟测试（监听 18081）
java -cp server\build\libs\timetable-server-all.jar com.example.timetable.server.SmokeTestKt
# 旧数据迁移
java -cp server\build\libs\timetable-server-all.jar com.example.timetable.server.MigrateToolKt timetables.json 你的邮箱 密码

# 预览：双击 start-web.bat，浏览器打开 http://127.0.0.1:8080/
```

### 后端环境变量

| 变量 | 默认 | 说明 |
|------|------|------|
| `PORT` | 8080 | 监听端口 |
| `WEB_ROOT` | 空 | Web 静态目录（start-web.bat 已设置） |
| `DB_URL` | `jdbc:sqlite:timetable-v2.db` | 生产改 MySQL |
| `DB_USER` / `DB_PASSWORD` | 空 | MySQL 凭据 |
| `JWT_SECRET` | dev 默认值 | 生产必须改 |
| `DATA_FILE` / `LOG_FILE` | timetables.json / server.log | 旧版共享数据与日志 |

## 6. 技术备注与踩坑记录（重要）

1. **Wasm 白屏三大坑**：HTML 需 `<canvas id="ComposeTarget">`（不是 div）；服务器需 COOP/COEP 头；中文需内置字体（skiko 不自动回退，当前内置 Noto Sans SC，OFL 开源许可）。
2. **coroutines 版本**：Compose 1.8 wasm 默认带 1.8.0（Kotlin 1.9 编译）与 Kotlin 2.1 运行时崩溃（ClassCastException），已在 commonMain 显式升级到 `1.10.2`——**不要降回**。
3. **@JsFun 返回 Long**：JS 返回 Number 会被拒（JsException），应返回 Double 再 `.toLong()`（Clock.wasm 已处理）。
4. **fat jar 打包**：必须用 Shadow 插件；手写 zipTree 合并会产出“列表正常但类加载器读不到”的坏 jar。
5. **Exposed 0.53**：`and`/`or`/`greater` 操作符的导入路径有问题，统一用“单条件查询 + Kotlin 侧过滤”规避（SyncService/ShareService 已按此写）。
6. **System.getenv 平台类型**：传给 Kotlin 非空参数时会空检查报错，用 `envOrNull() ?: ""` 兜底（Db.kt）。
7. **gradlew.bat**：`-P`/`-D` 带 `=` 会被拆分（报“task not found”），属性写入 gradle.properties 或分步执行。
8. **沙箱限制（仅本 Codex 环境）**：`toRealPath` 在用户目录被拒（影响 javac/AGP 签名）、Kotlin 守护进程需提权、网络按回合授权；正常机器不受影响。
9. **Web 端**：恢复 localStorage（Settings()）后刷新保留数据；PWA 离线壳已启用。
10. **旧共享码**：仍可用；登录账号后优先走账号同步；数据迁移用 MigrateTool。
