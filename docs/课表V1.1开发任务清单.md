## 阶段 C：批量导入

- **需求**：FR-106（V1.1 落地为 **CSV，Excel 可直接打开/编辑/另存**；.xlsx 解析在 KMP 无通用库，留 P2，桌面端可后续用 POI 增强）。

## 关键实现说明与风险

1. **字段向后兼容**：新字段全部带默认值，`CourseRepository` 的 JSON 已开 `ignoreUnknownKeys`，旧数据可直接加载；后端 DTO 同步加字段，避免云同步丢数据。
2. **导入用 CSV 而非 .xlsx**：KMP 无跨端通用 Excel 解析库；CSV 可用 Excel 打开编辑，四端统一“粘贴导入”最稳。桌面端后续可加 POI 支持 xlsx（P2）。
3. **通知能力差异**：Web 端无本地通知，V1.1 降级为页面提示；Android 13+ 需运行时申请通知权限。
4. **深色模式**：现有大量硬编码颜色（顶栏蓝、课程卡片白字、边框色），需逐一适配，避免“深色但局部刺眼”。
5. **云同步兼容**：V1.1 仍用现有共享码后端（JSON 文件）；字段扩展后需先部署新 server jar（T1.3），否则旧服务会丢新字段。
