# 课表 V1.1 手动回归清单

| 项目 | 内容 |
|------|------|
| 版本 | V1.1（体验版） |
| 日期 | 2026-08-12 |
| 用途 | 发布前逐项人工验证；在“实际结果”填 PASS/FAIL，FAIL 时备注现象 |

## 0. 环境准备

- [ ] Web：`gradlew.bat :composeApp:wasmJsBrowserDistribution` → `start-web.bat` → Edge/Chrome 打开 `http://127.0.0.1:8080/`
- [ ] 桌面：`gradlew.bat :composeApp:desktopJar` → `gradlew.bat :composeApp:run`
- [ ] Android：`gradlew.bat :composeApp:assembleDebug` → 安装到真机
- [ ] iOS*：需 macOS + Xcode（本清单中带 * 的项暂跳过，留待 iOS 验证）

---

## 1. 课程编辑

| # | 操作 | 预期 | 实际 |
|---|------|------|------|
| 1.1 | 新增课程，只填名称+星期+节次 | 保存成功，网格出现课程卡片 | |
| 1.2 | 编辑课程，设置“单周 / 第 1~16 周 / 备注” | 保存后编辑框再次打开值不变 | |
| 1.3 | 起始周填 10、结束周填 3（颠倒） | 保存后自动纠正为 3~10 | |
| 1.4 | 点击空白格新建 | 对话框星期/节次已预填 | |
| 1.5 | 删除课程 | 卡片消失；再重启应用不恢复 | |
| 1.6 | 点“清空” | 网格清空，重启后仍为空 | |

| # | 操作 | 预期 | 实际 |
